# 2026-11-26

## Aimbot: instant snap + lock (mouse lag fix)

Problem reported: crosshair neither snapped to the detected point instantly nor
stayed locked there; it should hold until the detection disappears.

Root cause: movement only happened inside `process_data()`, i.e. once per model
frame (~34 FPS / 29 ms), and the px-per-count seed from config was wrong, so
steps undershot and crept.

### What changed
- `logic/mouse.py`: `MouseThread` now owns a high-rate aim loop (`aim_loop`,
  `mouse_aim_tick_ms` = 4 ms / 250 Hz). The detection thread only publishes a
  goal via `set_target()`; `release_target()` drops it the same frame.
  - Goal tuple `(x, y, w, h, cls, stamp, goal_id)`; per-goal learning on
    `goal_id` change.
  - One push per detection: an in-flight guard makes later ticks in the same
    frame return `(0,0)`, because the effect of a push is invisible until the
    next detection.
  - Additive-offset calibration: `true_pxpc = (err_before - err_after)/counts`.
  - Per-axis `_k_x/_k_y` (global, slow EMA 0.22) + per-target line (fast),
    times depth ratio and `_aim_depth_scale`.
  - Axis inversion learned by sign contradiction (`along < -4.0`, two in a
    row); once flipped an axis STAYS flipped. `_axis_samples` is reset on flip.
  - `n_sign_known(axis)` = `_axis_samples[axis] >= 2` — tells "direction
    established" from "still probing", so harnesses do not flag the
    unavoidable first probe as overshoot.
- `logic/frame_parser.py`: `_handle_no_detections()` calls
  `mouse.release_target()` on the first lost frame (no grace).
- `run.py`: `mouse.start()` at init, `mouse.stop()` in `finally`;
  pause (F3) calls `mouse.release_target()`.
- Config keys added (`config.ini` + `logic/config_watcher.py`):
  `mouse_aim_tick_ms`, `mouse_release_ms`, `mouse_reaction_delay_ms`,
  `depth_fov_deg`, `depth_ref_height_px`, `predict_lookahead_ms`.

### Verification (all 0 failures)
- `tools/test_aim_lock.py` — 6 cases incl. 3x/0.4x sens error, jitter,

- `tools/test_aim_sweep.py` — 8 sens multipliers x 3 offsets + invY.
